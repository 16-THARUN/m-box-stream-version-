# Contributing

Thank you for helping. Before your first pull request is merged, you are asked to agree to a short contributor licence agreement (CLA): you keep the copyright to your work and give the project owner the right to use it in m-Box apps under GPL-3.0 and other licences. This keeps the shared core usable in both m-Box Stream and m-Box Player.

Please:
- open an issue before a large change;
- keep pull requests small and on one topic;
- never commit keystores, `keystore.properties`, `local.properties` or any secret;
- make sure `./gradlew assembleDebug` passes.
